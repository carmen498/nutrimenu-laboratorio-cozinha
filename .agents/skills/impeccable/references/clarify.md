# Clarify

> Modified from Impeccable v4.1.3 for Nutrimenu. See [NOTICE.md](../NOTICE.md) and [LICENSE](../LICENSE).

Improve interface language so users understand what happened, what matters, and what they can do next. Preserve factual meaning, established terminology, brand voice, and legal effect.

## Read the flow

Review the whole interaction path rather than isolated strings. Find ambiguous verbs and nouns, internal jargon, vague outcomes, inconsistent terminology, missing consequences, weak recovery, redundant copy, and text that fails at realistic widths.

For each state, establish:

1. the fact the user needs now;
2. the next available action;
3. supporting context that changes the decision;
4. a tone proportionate to the consequence.

Say each idea once.

## Write by function

- Actions name the outcome, not the gesture. Destructive actions name the object and consequence.
- Forms use persistent labels; placeholders are examples. Requirements appear before submission.
- Validation explains what needs attention and how to correct it without blaming the user.
- Errors state what failed, why when known, and how to recover. Do not invent causes or promises.
- Empty states distinguish first use, no results, filters, permissions, and failure.
- Success confirms the completed outcome and only adds a next step when it changes what the user should do.
- Help text answers an implicit question instead of repeating the control.

Use plain PT-BR while preserving terminology the audience genuinely knows. Complete translatable messages are preferable to concatenated fragments. Keep variables structured, allow expansion, and align screen-reader names with visible outcomes.

Em dashes are acceptable in PT-BR legal or editorial copy when they clarify meaning. Ask before changing legal, nutritional, pricing, subscription, privacy, or permission language.

## Verify

Check comprehension, actionability, factual accuracy, terminology, target widths, 200% zoom, long names, pluralization, dynamic values, accessible names, and tone. The final copy is as short as it can be without removing meaning or recovery.
